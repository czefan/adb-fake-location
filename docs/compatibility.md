# 真机兼容性验证记录

日期：2026-10-10

当前状态：所有真机试验已结束，手机恢复检查已通过。下文中“保留用户 GPS 会话”等描述是当时试验过程，最终状态以文末的恢复检查为准。

## 设备与范围

- 手机：realme RMX5010，Android 16 / SDK 36。
- 高德地图：17.00.0.2005。
- 工具：当前 Go 修订版，官方 ADB 测试提供商方式。
- 用户授权短时可恢复定位测试；未安装软件、未修改应用数据、未刷机或更改系统文件。

## 已确认的系统行为

1. `cmd location help` 和 `-h` 在此设备上打印完整帮助，但返回退出码 255。工具已针对完整有效的只读帮助响应兼容此行为，其他命令的失败处理不变。
2. 用户开启的 GPS 模拟会话能持续更新系统位置，系统提供商和位置对象均带 mock 标记。
3. 高德在前台时有 GPS 定位请求，系统统计的位置投递计数增加。仅凭此计数不能证明应用界面采用了模拟数据。

## 高德受控对照测试

| 条件 | 观察结果 |
| --- | --- |
| 用户原有 GPS 模拟会话 | 高德仍显示原来的位置 |
| GPS 会话保持不变，临时将 network 提供商模拟到同一点 | 约 32 秒内发送 27 次网络模拟位置，GPS / network 均确认处于 mock 状态；高德重新居中后仍显示原来的位置 |

只操作了高德地图的重新居中按钮，没有发起导航、发送位置或执行其他业务操作。观察前、中、后均检查了地图画面。

结论：在这次设备与应用版本组合下，当前 GPS 模拟方式以及本次 GPS + network 同点对照均未使高德采用目标位置。不能将原因简单归结为缺少网络定位模拟，也不能据此证明所有高德相关应用均不兼容。究竟是应用选择定位来源、mock 过滤、缓存还是厂商扩展行为，尚未确定。

当前将手机高德地图列为“未兼容”，不把这次无效的 network 试验加入默认功能，也不承诺更换网页地图 API 能解决手机 App 定位问题。

## 恢复检查

- 临时 network 测试提供商已移除，恢复为原系统提供商 `com.oplus.location`。
- shell UID 的 AppOps 模式保持测试前的 `allow`，本次没有更改该授权。
- 用户原有的 GPS 模拟会话、目标坐标保持不变；没有替用户停止该会话。
- 本地试验恢复记录显示 `pendingCleanup: false`，无本次试验遗留的网络提供商待清理项。

这是一份针对当前组合的实测记录，不是所有 Android 系统或所有使用高德/腾讯地图的第三方应用的兼容性结论。

## 追加观察：高德启动跳回与腾讯地图

用户补充观察：高德刚打开时短暂显示模拟位置，随后跳回实际位置。该启动过渡未单独录屏复现，因此保留为用户观察。它提示启动时展示的位置与后续定位结果不同，可能涉及缓存或后续更新覆盖，不能单凭此现象确定防检测机制。

腾讯地图版本：11.6.0，包名 `com.tencent.map`，沿用同一部手机和用户已开启的 GPS 模拟会话。

- 前台地图截图确认蓝点仍位于实际位置，未跟随模拟目标。
- GPS 测试提供商持续更新，腾讯有多个普通 GPS 订阅，精确定位授权正常。
- 两次系统快照中，腾讯的 GPS 位置投递统计从 714 增至 2055；这个统计并不等于应用界面采用了该位置。
- 腾讯同时订阅卫星状态与原始 GNSS 测量，GNSS measurement events 从 266 增至 778。测试提供商替换的是系统 Location 数据，并未一并替换这些硬件信息；这提供了另一条值得排查的线索，但不能证明腾讯最终使用哪条通道决定蓝点。
- 应用与系统相关日志中未找到足以明确证明“主动拒绝模拟位置”的诊断信息。

腾讯的 GPS + network 同点试验完成了系统层操作与清理，但中途截图为黑屏，无法确认界面结果。随后补测时检测到手机已熄屏，在修改任何状态前退出。因此，腾讯的结论仅为“当前 GPS 模式下未跟随”，双来源模式的界面兼容性仍属未验证，不能照搬高德的结论。

本次临时 network 提供商已移除，原系统网络定位服务 `com.oplus.location` 和原 AppOps 状态保持一致；用户原有 GPS 会话继续保留。未唤醒或解锁手机，也未修改屏幕超时设置。

## 结束所有测试后的最终恢复（已确认）

用户要求结束试验并清除测试状态后，已停止桌面模拟任务，移除 GPS 测试提供商，并撤回 ADB shell UID 和 shell 包的显式模拟定位授权至系统 `default` 模式。原先这些授权处于 `allow`，这次撤回是按用户要求结束全部测试进行的清理，不是声称已知测试前的历史授权值。

为刷新残留模拟缓存，定位服务短暂关闭后恢复为原来的开启状态；用户解锁并打开地图后，已只读确认：

- 系统定位开关为开启。
- `gps`、`network`、`passive`、`fused` 均没有测试提供商标记。
- GPS、network 和 passive 的最近位置已是真实定位数据，无 mock 标记；fused 当前没有缓存位置。
- shell UID 和 shell 包的模拟位置授权均为 `default`。
- 桌面模拟进程已结束，用户数据目录中没有待恢复的 `session.json`。

临时网络试验记录均已清理完成。项目整理阶段不再执行手机状态修改。
